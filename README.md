## 🚁 Flagship: MARK-1

An autonomous inspection drone designed as a **5-layer stack**. It is a research asset, a founding prototype and proof that the full pipeline works on-device.

| Layer | Stack |
|---|---|
| 🧠 **Edge LLM** | Ollama · Phi-3 · Llama 3.2, onboard reasoning with no cloud round-trip |
| 👁️ **Perception** | YOLOv11 · ByteTrack · depth estimation |
| 🧭 **Autonomy / Nav** | ROS 2 · Pixhawk · ORB-SLAM3 · NISAR SAR terrain priors |
| 📡 **Comms** | Secure **FANET** (Flying Ad-hoc Network), built with Rahul (cybersecurity) |
| 🖥️ **Ground Station** | React · FastAPI · WebRTC live telemetry |

## 🛰️ ISRO / NISAR: SAR Data Processing

Polarimetric decomposition pipelines on **L-band and S-band NISAR data**, running on a dual-DGX H100 cluster under the NISAR Mission Science Team.

- Pauli, Freeman-Durden, Yamaguchi and H-A-α decompositions
- Independently flagged **S-band compact polarimetry** as a key research finding
- ACRS (Asian Conference on Remote Sensing) abstract in progress
- Turning the pipeline into a modular, production-grade Python package
